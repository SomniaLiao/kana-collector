# 假名遊戲學習站

以 Phaser.js 製作的日語假名遊戲式學習網站，提供角色蒐集與翻牌配對兩種練習方式。網站使用 Vite 建置為靜態頁面，並透過 GitHub Pages 發布。

## 線上遊玩

- [遊戲入口](https://somnialiao.github.io/kana-games/)
- [01 假名蒐集任務](https://somnialiao.github.io/kana-games/collector/)

- [GitHub 專案](https://github.com/SomniaLiao/kana-games)

## 遊戲內容

### 01 假名蒐集任務

閱讀畫面提示並操控角色蒐集正確答案，練習「あ行」至「な行」共 25 個平假名。題目會交替以假名或赫本式羅馬拼音提示，每題答對得 1 分；答錯不扣分，會留在原題重新作答。

- 電腦：使用方向鍵或 WASD 移動。
- 手機與觸控裝置：按住遊戲畫面中的方向按鈕移動。
- 共 5 個關卡，每關練習一行假名。

### 02 翻牌記憶室

翻開卡片，配對假名與羅馬拼音，從記憶中提取讀音。可選擇平假名或片假名，以及清音、濁音與半濁音、拗音等練習範圍。每組正確配對得 1 分。

- 平假名與片假名各收錄 104 組音節配對，合計 208 組：清音 46 組、濁音與半濁音 25 組、拗音 33 組。
- 可用滑鼠或觸控翻牌，也可用方向鍵選牌並按 Enter。
- 頁面另附促音與長音的規則說明卡。

## 學習範圍

記憶室涵蓋平假名與片假名的清音、濁音、半濁音及拗音。促音與長音以規則卡說明；「ティ」、「ファ」等外來音組合目前尚未收錄，預計作為後續擴充內容。兩款遊戲採用赫本式羅馬拼音，例如 `shi`、`chi`、`tsu`。

## 本機啟動

需求：Node.js 20.19 以上版本（或 22.12 以上版本）與 npm。

```sh
npm ci
npm run dev
```

依終端機顯示的本機網址開啟網站入口。入口頁、蒐集任務與記憶室會分別連到對應頁面。

## 建置與預覽

```sh
npm run build
npm run preview
```

建置結果會輸出至 `dist` 資料夾。GitHub Actions 會在 `main` 分支有更新時建置網站並發布到 GitHub Pages。

## 使用技術

- [Phaser](https://phaser.io/) 4：遊戲畫面與互動
- [Vite](https://vite.dev/)：本機開發與靜態網站建置
- GitHub Pages：網站發布

網站在瀏覽器端執行，不需要帳號或後端服務。
