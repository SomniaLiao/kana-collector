# 假名蒐集任務

使用 Phaser.js 製作的平假名與赫本式羅馬拼音辨識遊戲。玩家以角色蒐集答案，五關共 25 字，答對得 1 分。

## 本機啟動

需求：Node.js 20.19 以上版本（或 22.12 以上版本）與 npm。

```sh
npm install
npm run dev
```

啟動後，依終端機顯示的本機網址開啟遊戲。

## 操作

- 電腦：方向鍵或 WASD 移動角色。
- 手機或觸控裝置：按住畫面下方方向按鈕移動。
- 手機建議直向遊玩；若在較矮的橫向畫面，遊戲會提示旋轉裝置。
- 錯誤答案不扣分，會留在原題；答對後自動進入下一題。

## 建置

```sh
npm run build
```

遊戲只在瀏覽器端執行，不使用帳號、後端服務或外部圖片素材。
